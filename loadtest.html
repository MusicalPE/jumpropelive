점프 Live (Lite) 부하 시험

학교 시트 스크립트(구글 앱스 스크립트)만으로 점프 Live를 돌리면 얼마나 늦는지, 몇 명까지 버티는지 재 봐요. 학생 기기 여러 대를 이 창 하나에서 흉내 내요.

1. 준비

  1. 새 구글 시트 → 확장 프로그램 → Apps Script → "부하시험_스크립트.gs" 내용을 붙여 넣고 저장
  2. 배포 → 새 배포 → 웹 앱 · 실행: 나 · 액세스: 모든 사용자 → 배포 → 웹 앱 URL 복사
  3. 아래 칸에 붙여 넣고 시작 (시트에는 아무것도 쓰지 않아요)

2. 결과

—화면에 보이기까지 평균 지연(초)
—느린 쪽 지연 (95%)
—실패한 요청
—초당 요청 수
요청횟수평균(초)95%(초)최대(초)실패
기기 수평균 지연95% 지연최대 지연실패초당 요청

지연 = 학생 기기에서 숫자가 올라간 순간부터 선생님 화면이 그 숫자를 받은 순간까지. Firebase(지금 점프 라이브)는 보통 0.3초 안팎이에요.
